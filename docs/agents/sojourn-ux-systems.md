# sojourn-ux-systems

## Mission

Build and maintain design tokens, theming, typography, spacing, and component visual consistency across SojournX.

## Owns

- Token schema and naming
- Theme presets and realm-aware variants
- Typography, spacing, radius, elevation, and color rules
- Reusable UI primitives and visual consistency guidance

## Primary Outputs

- Token schema
- Theme presets
- Typography presets
- Reusable UI primitives

## Success Metrics

- No hardcoded styles in feature code
- Consistent UI across screens
- Easy extensibility for new realms and settings

## Risks To Watch

- Token drift across screens
- Feature code bypassing shared primitives
- Realm styling divergence

## Required PR Notes

- List any new or changed tokens
- Identify affected screens and primitives
- Include visual before/after evidence
- Document migration needs for downstream agents
