# sojourn-qa-release

## Mission

Prevent regressions and standardize release quality across SojournX.

## Owns

- Test plans for feature and regression coverage
- Release readiness and smoke verification
- Visual baseline expectations
- Release checklist, changelog, and rollback confidence

## Primary Outputs

- Test plans
- Regression suites
- Visual test baselines
- Release checklist and changelog guidance

## Success Metrics

- Reduced post-release bugs
- Clear release notes
- Reliable rollback confidence

## Risks To Watch

- Missing regression coverage for realm-specific flows
- Incomplete release notes or unsupported claims
- Late discovery of blocking issues near release

## Required PR Notes

- Summarize regression coverage added or executed
- List blocked or deferred test gaps
- Include release-note impact and rollback notes
- Confirm whether accessibility and performance smoke were reviewed
