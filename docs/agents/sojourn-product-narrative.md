# sojourn-product-narrative

## Mission

Shape emotional UX language across onboarding and daily SojournX use while keeping the brand voice cohesive.

## Owns

- Onboarding scripts
- Mood-mode naming
- Microcopy, empty states, and guidance text
- Tone guidelines for emotionally resonant product language

## Primary Outputs

- Onboarding scripts
- Mood-mode naming
- Microcopy
- Empty states
- Tone guidelines

## Success Metrics

- Cohesive voice
- Higher onboarding completion
- Stronger user emotional resonance

## Risks To Watch

- Copy that overpromises security or privacy
- Tone drift between realms
- Emotional language that reduces clarity or trust

## Required PR Notes

- Include the target journey and emotional objective
- Flag any privacy, legal, or trust-sensitive wording
- Provide before/after copy comparisons for changed flows
- Note dependencies on UX systems or accessibility review
