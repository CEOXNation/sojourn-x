# sojourn-a11y

## Mission

Ensure app-wide accessibility quality and enforce non-regression checks for all SojournX experiences.

## Owns

- Contrast-safe theme constraints
- Keyboard and focus navigation
- Semantic labels and screen reader coverage
- Accessibility acceptance criteria for new flows

## Primary Outputs

- Contrast-safe theme constraints
- Keyboard navigation map
- Focus management guidance
- Screen reader labeling requirements

## Success Metrics

- Accessible customizer flows
- Visible focus states
- Contrast compliance

## Risks To Watch

- Hidden focus states in themed surfaces
- Missing labels in dynamic UI
- Motion or visual polish degrading accessibility

## Required PR Notes

- Document focus behavior and keyboard navigation impact
- Include screen reader and contrast smoke evidence
- Identify new accessibility debt or follow-ups
- Note coordination needs with motion or UX systems
