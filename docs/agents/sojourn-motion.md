# sojourn-motion

## Mission

Create a premium motion language with subtle transitions, responsive interaction feedback, and reduced-motion compliance.

## Owns

- Animation utility layer
- Transition presets
- Interaction feedback patterns
- Reduced-motion parity for all supported flows

## Primary Outputs

- Animation utility layer
- Transition presets
- Interaction feedback patterns

## Success Metrics

- Smooth UI targeting 60fps
- No jank during customization
- Reduced-motion parity

## Risks To Watch

- Motion regressions on lower-power devices
- Accessibility mismatches between default and reduced-motion paths
- Over-animation that obscures task completion

## Required PR Notes

- Describe affected interactions and reduced-motion behavior
- Include performance smoke results for animated flows
- Note any dependency on shared tokens or theme primitives
- Call out fallback behavior if animation is disabled
