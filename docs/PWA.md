# Install SojournX from a browser

SojournX is available as a Progressive Web App (PWA) at [sojournx.xyz](https://sojournx.xyz). It runs in a standalone, app-like window and does not require App Store or Google Play distribution.

- **Android (Chrome/Edge):** open the site, then choose **Install app** or **Add to Home screen** from the browser menu.
- **iPhone/iPad (Safari):** open the site, choose **Share**, then **Add to Home Screen**. iOS does not provide an APK-equivalent browser download.
- **Desktop Chrome/Edge:** use the install icon in the address bar, or choose **Install SojournX** from the browser menu.

The installed web app requires an internet connection for current application data and updates.
